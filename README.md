One original line roasting the phone I use every day — its autocorrect turns a flat "ok" into an over-eager "OK!", as if it just agreed to a plan I never made. `main.py` (Python 3.13 stdlib only, deterministic, no network) writes that line to `/output/entry.txt` for the "One-Line Roast: The Gadget You Use Every Day" bounty on make.fun.

## The roast

> My phone autocorrects 'ok' to 'OK!' like it's thrilled about a plan I never agreed to.

86 characters — comfortably inside the 200-character limit, one line, one gadget, one specific gripe.

## Run it

```sh
python3 main.py
```

Local run (writes to `./out/entry.txt` instead of `/output/entry.txt`):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
